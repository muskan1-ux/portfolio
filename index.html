AI Agentic Report Validation & Exception Triage Platform

Open-source rebuild of the enterprise workflow described below — runnable, not just described

At TCS, I helped build a client reporting engine where exceptions raised during report generation are automatically triaged by a multi-step AI agent instead of sitting in a human review queue. To make that claim verifiable, I rebuilt the architecture from scratch as an open-source project: an event-driven engine on Java 21, Spring Boot, Kafka, and Redis, with an agent module that prefers a real Claude reasoning call and falls back to a deterministic rule engine when no API key is set — so the whole thing still runs end to end, offline.
