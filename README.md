# Muskan Sharma — Portfolio

A single-page portfolio built as a static HTML/CSS/JS site, showcasing my
work as a Java Application Engineer — microservices, APIs, and AI-assisted
backend systems.

**Live site:** https://muskan1-ux.github.io/portfolio/

## What's on it

- **About** — background as a Java engineer focused on event-driven
  microservices and AI-assisted engineering
- **Experience** — roles at Tata Consultancy Services and Intellect Design
  Arena
- **Featured project** — a breakdown of
  [ai-agentic-report-platform](https://github.com/muskan1-ux/ai-agentic-report-platform),
  including architecture flow and how each resume claim maps to real code
- **Skills** — languages, backend/microservices, messaging & data,
  AI-assisted development, frontend, and DevOps tooling
- **Certificates** — Google, IBM, and Coursera credentials
- **Contact** — email, GitHub, LinkedIn

## Tech

Plain HTML, CSS, and vanilla JavaScript — no build step, no framework.
Fonts are loaded from Google Fonts (IBM Plex Sans / IBM Plex Mono).

## Running locally

Clone the repo and open `index.html` directly in a browser, or serve it:

```bash
git clone https://github.com/muskan301-oss/portfolio.git
cd portfolio
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Hosted with GitHub Pages, deploying from the `main` branch's root folder.
Any commit to `index.html` redeploys automatically within a minute or two.
